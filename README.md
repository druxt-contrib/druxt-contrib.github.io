# Druxt Contrib

> Documentation for the community modules that extend a Druxt site.

[Druxt](https://druxtjs.org) is the fully decoupled Drupal and Nuxt
framework. The modules listed here are built and maintained by the community
alongside it, each one adding a part of Drupal that a Druxt site can render.

A module with a documentation site of its own is served under this domain, at
its repository name. The rest are documented in their repositories, and every
one of them says where it lives.
